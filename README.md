# FOUR WORLDS, ONE SQUAD

Bible créative et référentiel de production de la série **FOUR WORLDS, ONE SQUAD**.

## Le projet

Quatre amis d'enfance, originaires de cultures et de pays différents, se retrouvent pour vivre des aventures, lancer des projets et se retrouver dans des situations souvent imprévisibles.

La série est centrée sur les quatre garçons. Les personnages secondaires interviennent selon les besoins des histoires.

## Format

- Épisodes courts de 1 à 2 minutes maximum.
- Format vertical 9:16, pensé pour TikTok, Instagram Reels et YouTube Shorts.
- Cible de durée habituelle : 90 secondes.
- Univers visuel : photoréaliste et cinématographique.
